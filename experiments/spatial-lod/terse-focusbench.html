TERSE FocusBench

6 tasks over the 23-document corpus. Condition C (TERSE-LOD) gets the full L0 MAP (one line per document, with addresses) plus the complete L1 of its 3 focus documents; conditions A (prose) and B (short) get the same character budget, filled from the start of the corpus and truncated. Each task asks 2 in-focus questions and 2 out-of-focus questions (about unloaded regions). Pre-registered predictions (written before any run): P1 — C matches full-context accuracy in focus; P2 — on out-of-focus questions C names the existing address or requests a fetch in ≥80% of cases, A and B in ~0%. Grading: LLM judge, 4 classes on out-of-focus (CORRECT / AWARE / HONEST-BLIND / HALLUCINATION). 144 calls. Local API mode required.
