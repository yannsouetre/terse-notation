TERSE StructBench

Do markers pay when the task is finding structure — every decision, every rule, every prohibition — inside one large context? Same 23 documents concatenated three ways (prose · short · TERSE), same extraction queries, measured on completeness (found / missing / invented) and output tokens (the reasoning-effort proxy). Gold lists were audited item by item against the prose by an independent model from another vendor: wrong items fixed, missing items added, ambiguous categories operationally defined in the query wording.
